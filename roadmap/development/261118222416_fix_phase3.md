# fix：Phase 3

## W3-2のモックとの照合で見つけた、サイドバーの項目の容量の抜け

- 区分：軽微な修正（要件・設計・確定事項を変えず、tasks・walkの構成も変えない）
- 内容：サイドバーのデバイスの一覧項目（`src/lib/components/DeviceListItem.svelte`）に、識別子（と「{store} 上」）のあとの「· 容量」がなかった。モックS01・S01j（`.dm`の行：識別子 ＋ 保存先 ＋ ` · ` ＋ 容量）に合わせて、容量（`formatBytes(device.size)`）を足した
- 理由：モックの要素の有無との不一致。T3-3の項目に「デバイスの一覧項目（ラベル名・ベンダー名・ほかN個・種別・ESPの数・マウント中の数・小さな帯）」とあり、容量の記載はなかったため、実装の取りこぼし
- 検証：`bun run check`が全段階通過
